# Daycraft

A productivity dashboard built with React and Vite to help manage daily tasks, track habits, and stay focused.

## Features

- Add, edit, complete, and delete tasks
- Set priorities for tasks
- Track task completion progress
- Customizable focus timer
- Add and track daily habits
- Personalized welcome screen
- Save data using local storage

## Tech Stack

- React
- JavaScript
- CSS
- Vite
